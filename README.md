# CONTROL ESCOLAR

## Descripción

Sistema web para la administración y control escolar de una institución educativa, permitiendo gestionar alumnos, profesores, administrativos y procesos académicos.

## Objetivo

Desarrollar una aplicación que facilite el control de inscripciones, calificaciones, pagos, reportes académicos y administración escolar.

## Pila Tecnológica

* Laravel
* PHP
* JavaScript
* HTML5
* CSS3
* MySQL
* Git y GitHub
